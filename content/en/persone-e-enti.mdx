# People and institutions

**People** and **Institutions** do not belong to a single year. You create them once and reuse them.

## People

Menu **People and organisations** → **People**.

- **First name** and **Last name** (required). The full name is composed automatically.
- **Institution** — institution already in the list
- **Photo** — optional
- **Bio** — richer text (headings, lists, optional images in the text)

List order can be changed by dragging, when a fixed order is needed in some views.

## Institutions

**Institutions**: organisation name and details. Link people to the right institution so you do not repeat the affiliation on every abstract.

<Callout>
  If you delete a person, the link disappears in abstracts that used them. Better to **correct** a record than delete it, if that person is already in a published programme.
</Callout>
