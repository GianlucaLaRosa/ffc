# Appendix

Each edition can have **at most one appendix**. It is the tabbed area at the bottom of the public page (texts, institutions, reviewers, projects).

## How to create it

Conference **Appendix** tab → **Create New**.

Do not create a second appendix for the same edition: the system blocks it. To change the content, **open the existing one**.

## Blocks (the tabs)

Each block has a **Title**: it is the tab label the public sees. You can add an icon.

Types:

| Block | Use |
| --- | --- |
| **Basic text** | Same layout blocks as the [Intro](/en/docs/testi-e-intro) tab (**Content**, **Accordion**, **Callout**, **Button**, **Quote**, **Separator**). The block **Title** is the public tab label. |
| **Institutions** | List of institutions, with optional exclusions. The public page shows **Italy** first (Italian regions A–Z), then other countries A–Z. |
| **Reviewers** | Reviewers |
| **Research projects** | Intro text plus the searchable list of **Appendix** rows from each abstract (see [Abstract](/en/docs/abstract)). Without this block, those rows stay hidden on the public site. |

Drag the blocks for tab order. You need at least one block.

<Callout type="info">
  For a welcome text use **Intro**. For reference material (lists, long acknowledgements) use the appendix.
</Callout>
