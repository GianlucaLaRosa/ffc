# Opening copy

In the **Intro** tab you build the top of the public page: welcome, explanations, notices, links.

It is not a single “wall of text”. Add **blocks**, one under the other, and drag them to change order.

## Block types

| Block (English name) | What it is for |
| --- | --- |
| **Content** | Text in one or more columns. Each column has a width. |
| **Accordion** | Questions that open on click (hours, short FAQs, notes). |
| **Callout** | Notice or information box. |
| **Cta** | Button with a link (registration, PDF, external site). |
| **Quote** | Highlighted quotation. |
| **Separator** | Visual divider. |

## Widths

From a large screen up, the row is like **12 columns**. Examples:

- **Full** = the whole row
- **Two thirds** = two thirds
- **Half** = half
- **One third** = one third

Two halves sit on the same row. If the sum goes over 12, the next block wraps. On a phone everything stacks, in the order you placed it.

<Callout type="info">
  You can open **preview** from the conference to see the intro on phone, tablet, and computer without publishing.
</Callout>

## Writing tips

- A clear title at the start, then short paragraphs.
- Do not repeat city, dates, and address here if you already have them in venue and days: the site shows them in other sections.
- For long lists (reviewers, projects) use the [appendix](/en/docs/appendice), not the intro.
